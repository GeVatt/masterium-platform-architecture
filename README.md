# B2B E-Commerce Platform: Masterium (Core Subsystem)

## 📌 Описание проекта
Данный репозиторий содержит технический паспорт и описание архитектуры B2B-платформы автоматизации учета, аналитики и взаимодействия с контрагентами (мастерами) розничной сети «Мастериум». 

* **Продакшн-версия продукта:** [app.masteriumgorod.ru](https://masteriumgorod.ru)
* **Архитектурный стиль:** Модульный монолит (Stateless-архитектура)
* **Ролевая модель доступа (RBAC):** Мастер, Администратор, Заявитель (доступ регулируется кастомными классами разрешений: `IsMasterOrAdmin`, `IsAdminUser`).

---

## 🛠 Технологический стек (Tech Stack)
* **Backend:** Python 4.2 (Django / Django REST Framework), миграция ядра на Node.js (**NestJS**).
* **Frontend & Mobile:** JavaScript (**Vue 3** Composition API, TypeScript, Vite, Pinia, Element Plus), Mobile Android (интегрированные адаптивные компоненты).
* **Инфраструктура & CI/CD:** **Docker / Docker-compose**, асинхронный ASGI-сервер **Daphne**, веб-сервер **Nginx**, ОС **Linux (Ubuntu)**.
* **Брокеры & Кэширование:** **Redis** (Очереди Celery, Pub/Sub для WebSockets, транзитный кэш).
* **СУБД:** PostgreSQL (Production), Django ORM / SQLAlchemy.

---

## 🏗 Архитектура бэкенда и структура компонентов

Проект спроектирован по принципу разделения на изолированные предметные домены (Bounded Contexts). Бизнес-логика полностью отделена от слоя представления (контроллеров/views) и вынесена в специализированный сервисный слой (`core.business_logic`).

### Структура предметных модулей (Django Apps / NestJS Modules):
* `users` — управление пользователями, сессиями и JWT-аутентификацией (`djangorestframework-simplejwt`).
* `products` & `sales` — учет номенклатуры, движения товарно-материальных ценностей (ТМЦ) и фиксация продаж.
* `payments` — баланс контрагентов, алгоритмы автоматического расчета выплат и аналитика доходности.
* `appointments` — логика тайм-слотов и система онлайн-записи мастеров в торговое пространство.
* `chat` & `notifications` — real-time коммуникации и push-уведомления.
* `file_imports` — подсистема парсинга и валидации внешних плоских файлов.
* `odata_integration` — шлюз интеграции с учетными системами 1С.
* `yougile_integration` — модуль двусторонней синхронизации с внешним таск-трекером.

## 🔄 Интеграционные интерфейсы и Data Flow

### 1. Стык с ERP 1С:УНФ через 1C OData API
Для обеспечения оперативного учета остатков и прозрачности взаиморасчетов реализована прямая интеграция бэкенда с облачным сервисом 1С по протоколу **OData (REST)** посредством выделенного клиента `odata_integration.client`.

* **Синхронизируемые сущности:** Справочники (Контрагенты, Договоры, Номенклатура), Документы (Приходные/Расходные накладные, Чеки ККМ, Возвраты, Выплаты).
* **Обеспечение идемпотентности:** Для предотвращения дублирования документов при сетевых задержках разработан механизм атомарного учета обработанных транзакций (`ProcessedDocument`) с уникальным индексом по связке `document_ref` + `master_id`.
* **Оптимизация производительности:** Внедрено транзитное кэширование тяжелых справочников номенклатуры в памяти процесса для снижения количества запросов к облачной 1С.

### 2. Асинхронный парсинг данных (Модуль `file_imports`)
Для резервных каналов обмена и пакетной загрузки исторических данных реализован конвейер импорта Excel/CSV (Остатки, Продажи, Цены) на базе библиотек **Pandas** и **OpenPyXL**:
* Валидация входных данных по строгой схеме до записи в БД.
* Логирование ошибок на уровне строк с поддержкой механизма частичной обработки пакета (Partial Processing).

### 3. Интеграция с YouGile REST API
Реализован прокси-клиент для синхронизации локальных сущностей с внешним таск-трекером, включая хранение и маппинг расширенных метаданных (приоритеты, подзадачи) в реляционной СУБД.

## ⚡ Инфраструктура, Очереди и Real-Time

Система спроектирована как **Stateless-архитектура** (авторизация по JWT, сессии WebSocket-каналов вынесены в Redis), что обеспечивает линейное горизонтальное масштабирование бэкенда за балансировщиком нагрузки.

## 📱 Фронтенд и Мобильная экосистема
Интерфейс представляет собой **SPA-приложение на Vue 3** с Composition API и TypeScript.
* **State Management:** Логика распределена по реактивным хранилищам **Pinia** (auth, appointments, products, sales, chats).
* **UI/UX & Адаптивность:** Сетка построена на CSS Grid / Flexbox с кастомизацией компонентов библиотеки **Element Plus**. Внедрены изолированные мобильные представления (`MobileBottomNav`, `MobileMenu`) для бесшовной работы со смартфонов.
* **Дистрибуция Mobile:** Реализован выделенный инфраструктурный эндпоинт (`core/mobile-app`) для безопасной отдачи собранных мобильных дистрибутивов (Android APK) конечным пользователям платформы.
